# T5 前端：各域资源的项目归属入口

## 目标

在构建任务、脚本任务、流水线、智能体的创建/编辑表单中提供"所属项目"选择器，并在各域全局列表页增加按项目过滤，使关联关系可建、可改、可查。

## 现状依据

- 表单页：`web/src/views/cicd/build-jobs/pages/main.vue`（列表+编辑一体）、`script-jobs/pages/main.vue`、`pipelines/pages/main.vue`、`ai/agents/pages/main.vue`
- 列表已有过滤先例：build-jobs 支持 `repository_id` / `keyword` / `tag`（`internal/cicd/handler/build_job_handler.go:54-62`）
- 项目下拉数据源：`GET /api/v1/projects`（T2 后全员可列；前端 `web/src/api/projects.ts` 已有客户端）
- 后端 `project_id` 字段与过滤参数由 T1 提供

## 改动清单

### 1. 项目选择器

- 新增轻量封装（如 `web/src/components/project-select.vue`）：下拉 + 可搜索（keyword 透传），数据源 `GET /projects?page_size=100`（超出时分页加载或远程搜索），允许清空（解除关联）
- 若 `@veltra/*` 已有合适的远程搜索选择组件，优先复用，不重复造轮子（先查 veltra-ui 技能/组件清单）

### 2. 四个表单接入

- 构建任务、脚本任务、流水线、智能体的创建/编辑表单各加"所属项目"字段（可空）
- 编辑回显：对象上的 `project_id` → 选中项（注意选项未加载时的占位回显）
- 提交时携带 `project_id`（清空传 null/不传，按 API-SPEC 约定）

### 3. 全局列表过滤器

- 四个全局列表页各加"项目"过滤下拉（同组件），与现有关键词/标签过滤并存
- URL query 同步（沿用各页现有的过滤状态管理方式）

### 4. 项目详情"新建"预填

- 消费 T4 面板"新建"按钮带来的 `?project_id=<id>`：打开新建表单时预填所属项目
- build-jobs 等"列表+编辑一体"页面需支持 query 触发新建弹窗并预填

### 5. 列表展示

- 各全局列表增加"项目"列（名称或 slug，点击可跳项目详情），数据来自资源对象 `project_id` 的关联展示——若后端未 join 返回项目名，第一版可只显示过滤器与表单，列展示降级为可选（避免为展示列改后端响应；若要加，后端在响应中补 `project_name` 并在 T6 更新契约）

## 实施步骤

1. 项目选择器组件
2. 四表单接入 + 回显
3. 四列表过滤器 + query 同步
4. 新建预填链路
5. `vp check` + 手工验证

- [ ] 创建构建任务时选择项目 → 保存后详情/编辑页回显正确 → 项目详情构建面板（T4）立即可见

- [ ] 四个全局列表页按项目过滤结果与后端 `?project_id=` 直调结果一致；与关键词等其他条件叠加正确

### 权限验证

- [ ] 仅有项目查看权限、无 cicd 写权限的用户：看不到新建/编辑入口（现状不变）
