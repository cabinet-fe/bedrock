**请求体**: （无则整节省略）

`body` 为对象时展开真实字段。继承 `BaseDTO` 时**必须**保留嵌套 `_shared`（禁止把其子字段摊到顶层）：

| 字段名    | 类型                   | 必填 | 说明                                      |
| --------- | ---------------------- | ---- | ----------------------------------------- |
| \_shared  | object                 | 是   | 共享上下文（BaseShared）；见下表或数据模型 |
| tableName | string                 | 是   | 主表表名                                  |
| data      | Record<string, object> | 是   | 主表字段与值                              |

`_shared` 展开（或锚点引用 [BaseShared](#baseshared)）：

| 字段名      | 类型                   | 必填 | 说明                              |
| ----------- | ---------------------- | ---- | --------------------------------- |
| moduleCode  | string                 | 是   | 模块编码                          |
| action      | string                 | 是   | `DRAFT` / `SAVE` / `SUBMIT`       |
| orgCode     | string                 | 是   | 组织代码                          |
| taskUser    | Record<string, string> | 否   | 任务用户                          |
| attachments | object[]               | 否   | 附件分组                          |

整段 `body` 不为对象（标量 / 数组等）时，字段名用 `` `_(body)_` ``（单元格内必须带反引号）：

| 字段名       | 类型     | 必填 | 说明               |
| ------------ | -------- | ---- | ------------------ |
| `_(body)_`   | number[] | 是   | 待提交记录 ID 列表 |

**响应体**（即信封里的 `data`）:

`data` 为对象时**必须展开真实字段**（来自 `resolve_types`）。禁止只写「返回 `UserInfo` 对象」而不给表。

| 字段名 | 类型   | 说明   |
| ------ | ------ | ------ |
| id     | string | 记录 ID |
| name   | string | 名称   |

同一 DTO 在本文多处出现时：可在文末 `## 数据模型` 写全定义，此处写「见 [UserInfo](#userinfo)」。

`data` 不为对象（标量 / 数组等）时，字段名用 `` `_(data)_` ``（单元格内必须带反引号）：

| 字段名      | 类型    | 说明     |
| ----------- | ------- | -------- |
| `_(data)_`  | boolean | 是否成功 |
