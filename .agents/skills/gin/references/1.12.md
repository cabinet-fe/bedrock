# Gin 1.12

本文件适用于 **1.12.x**。按下面写。**最低 Go 是 1.25**（`go.mod` 的 `go` 行不够就先升语言版本，语法见 go 技能）。BSON 绑定走 mongo-driver **v2**。

## 1.10 / 1.11 仍该用（细节按需打开旧档）

| 档 | 现在仍用 |
| --- | -------- |
| 1.10 | `ShouldBind*`、`ShouldBindBodyWith`、`OptionFunc`、`SetTrustedProxies(nil)` / CIDR、goroutine `c.Copy()` |
| 1.11 | `ShouldBindPlain`、`unixMilli` / `unixMicro`、typed `GetXxx`、表单 collection、`OnlyFilesFS` |

不要 `BindWith`。HTTP/3 仍实验，默认不用。

## Context

```go
c.Set("bindErr", err)
if e := c.GetError("bindErr"); e != nil {
	// 不是 error 或没有 key → nil
}
errs := c.GetErrorSlice("bindErrs")

c.Delete("bindErr") // 从 Keys 去掉；不要再 Set(nil) 冒充删除
```

`GetError` / `GetErrorSlice` 只读 `c.Keys`。handler 里 `c.Error(err)` 仍进 `c.Errors`，统一错误中间件继续看 `c.Errors`。

Unix socket 进来的请求会信任 `X-Forwarded-For`。`ClientIP` 能处理多个 XFF 值。`Flush()` 在 ResponseWriter 不是 `http.Flusher` 时不再 panic。

## 绑定与渲染

- URI / query 绑定会调字段的 `encoding.UnmarshalText`。自定义 ID 类型实现该接口，不要在 handler 里 parse。
- 空 form 值、空 slice/array 按 1.12 的行为处理；不要为「空数组当错误」再包一层。
- 需要 BSON：`c.BSON(...)` / 对应 render，不要手搓 encoder。依赖必须是 mongo-driver v2。
- 内容协商可以出 protobuf。项目不是 protobuf 响应就不要开。

## 引擎

需要按转义后的路径匹配时设 `engine.UseEscapedPath = true`（会覆盖 `UseRawPath`）。默认不要动。字面量 `:` 的路由与 `engine.Handler()` 在 1.12 可用。

日志可配置跳过 query string（避免把 token 打进日志）。没有需求保持默认。
