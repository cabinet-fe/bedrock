# Gin 1.11

本文件适用于 **1.11.x**。1.10 的 `OptionFunc` / `ShouldBindBodyWith` / `BindUnmarshaler` 照用。不要用 1.12 才有的 API（`GetError` / `GetErrorSlice`、`Context.Delete`、BSON render、protobuf 内容协商、URI/query 的 `encoding.UnmarshalText`）。

## 1.10 仍该用（细节按需打开 1.10 档）

`ShouldBind*`、`ShouldBindBodyWith`、`OptionFunc`、`SetTrustedProxies`、goroutine 用 `c.Copy()`。不要 `BindWith`。

## 纯文本与时间

```go
var body string
if err := c.ShouldBindPlain(&body); err != nil {
	c.JSON(http.StatusBadRequest, gin.H{"error": err.Error()})
	return
}
```

`time.Time` 的 form/json 可用 `unixMilli` / `unixMicro` 格式 tag，不要自己除 1000。

## 表单集合

数组 query/form 用 collection format；切片可设默认值。自定义字符串切片走 form tag 的 unmarshal，不要 `strings.Split` 一套。

## Context `GetXxx`

用框架提供的 typed getter（1.11 覆盖更多原生类型）。不要 `c.Get` 再断言。

## 静态文件

只要文件、不要目录列表：用已导出的 `OnlyFilesFS` 包一层 `http.FS`。

## HTTP/3

`RunQUIC` 等基于 quic-go 的入口是**实验**。默认业务代码不要用；用户明确要求再写，并接受实验 API 可能变。
