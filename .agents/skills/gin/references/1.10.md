# Gin 1.10

本文件只适用于 **1.10.x**。不要用 1.11 / 1.12 才有的 API（`BindPlain`、`GetError` / `GetErrorSlice`、`Context.Delete`、BSON render、URI/query 的 `encoding.UnmarshalText`）。

`BindWith` 已弃用，不要用。

## 引擎选项

`gin.New` / `gin.Default` 直接收 `OptionFunc`（`func(*gin.Engine)`）。创建后再改用 `engine.With(...)`。没有包级 `gin.With`。

```go
r := gin.New(func(e *gin.Engine) {
	e.RedirectTrailingSlash = false
})
```

## 同一 body 绑多次

默认 body 只能读一次。要绑成不同 struct 用 `ShouldBindBodyWith`（先缓存再解码），不要自己 `io.ReadAll` 再搓一套。

```go
if err := c.ShouldBindBodyWith(&a, binding.JSON); err != nil { /* ... */ }
if err := c.ShouldBindBodyWith(&b, binding.JSON); err != nil { /* ... */ }
```

自定义 query/form 类型实现 `binding.BindUnmarshaler`（`UnmarshalParam(string) error`），不要在 handler 里手工 `strconv`。

可覆盖默认 binding 实现；没有明确需求不要动。

## 日志与鉴权（框架自带）

- `LoggerConfig` 可用用户函数 skip 某些请求（如 `/healthz`）。
- 代理场景的 Basic Auth 用 `BasicAuthForProxy` + `AuthProxyUserKey`，不要跟普通 `BasicAuth` 混。
- YAML：`application/yaml`（RFC 9512）。

## 其它 1.10

- `Context.Value` 跟标准库一致：找不到返回 `nil`。
- `c.Copy()` 会带上 `fullPath`，且拷 `Keys` 时是安全的；goroutine 仍然必须 Copy。
- catch-all 路由不要跟冲突的 wildcard 写在一起（1.10 修过 panic）。
